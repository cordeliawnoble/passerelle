PRÉLUDE C86

Correctif import médias personnages :
- l'import n'est plus déclaré réussi sur la seule absence d'erreur Supabase ;
- Passerelle met à jour la fiche personnage puis relit/vérifie réellement le lien enregistré ;

- les erreurs sont affichées au lieu d'un faux OK ;
- bouton « Réconcilier les médias » pour récupérer les médias déjà importés lors du bug C85.

C86 contient tout le cumul précédent.
